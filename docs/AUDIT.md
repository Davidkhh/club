# Аудит и статус (тестовая версия, без production-деплоя)

## Найдено
- Все фото (5 шт.) — внешние GetCourse-ссылки, часть из них `thumbnail` (низкое разрешение), подключены как CSS-фон: нет alt, lazy-loading, srcset, размеров (риск LCP/CLS).
- Все CTA ведут на `clubschastya-yoga.ru/main#price`; собственных форм нет, регистрация только через GetCourse.
- Шрифт Cormorant подключён через CSS `@import` (блокирует отрисовку) — перевести на `next/font`.
- Расписание: у четырёх занятий есть фиксированный день/время (МСК), у двух — «по анонсу».
- Сайт закрыт от индексации (`robots: noindex`) — убрать при запуске; тогда добавить `robots.txt` и `sitemap.xml`.
- Цены 3 300 ₽/мес и 2 990 ₽ со 2-го месяца взяты из исходного сайта, актуальность не подтверждена владельцем.

## Сделано в этом проходе
Canonical, OG/Twitter, themeColor; skip-link; видимый focus; закрытие меню по Escape и `aria-controls`.

## НЕ проверено (нет сети/браузера в среде)
`npm install`, lint, `tsc`, `next build`, Lighthouse/Core Web Vitals, проверка ссылок, адаптивность на 360–1440 px, консоль браузера.
