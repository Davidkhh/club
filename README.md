# SCHASTYA — новый frontend клуба «Клуб Счастья»

Самостоятельный проект на Next.js App Router + React + TypeScript. Исходный сайт не изменяется. Текущая версия — frontend-концепт, который сохраняет найденные тексты, направления, часть расписания, отзывы, публичные контакты и ссылки на GetCourse.

## Требования
- Node.js 20.9+ (рекомендуется актуальная LTS)
- npm

## Запуск
```bash
npm install
npm run dev
```
Откройте http://localhost:3000.

## Production build
```bash
npm run build
npm start
```

## Структура
- `app/page.tsx` — главная страница и секции
- `app/globals.css` — дизайн-система, адаптивность, анимации
- `app/layout.tsx` — metadata и корневой layout
- `components/Header.tsx` — адаптивная навигация
- `components/FAQ.tsx` — раскрывающийся FAQ
- `components/Reveal.tsx` — появление секций с учётом reduced motion
- `lib/content.ts` — контент, расписание, отзывы, внешние ссылки
- `public/assets/` — место для локальных копий изображений после подтверждения прав и загрузки оригиналов

## Внешние интеграции и ограничения
- Регистрация, оплата, доступ к курсам и автопродление остаются на действующей платформе GetCourse; кнопки пока ведут на подтверждённую публичную страницу тарифов.
- Форма заявки намеренно не имитируется: на текущем этапе используется существующий внешний сценарий.
- Изображения из открытых ссылок GetCourse использованы как ссылки на оригинальные ресурсы; для production следует подтвердить право использования и сохранить локальные оптимизированные копии, где это разрешено.
- В расписании есть записи вида «с сентября» и дата старта 10.09; они помечены как требующие актуализации.
- Цены с исходного сайта: основной тариф 3 300 ₽/мес., 2 990 ₽ со второго месяца при автопродлении; дополнительные тарифы 7 700 ₽ и 990 ₽ присутствуют в исходном HTML, но их состав и актуальность требуют ручной проверки.
- Юридические ссылки ведут на страницы исходной платформы; юридические тексты не копировались в новый frontend.

## Проверки
В текущем контейнере доступен Node.js, но сетевой DNS недоступен, поэтому установить npm-зависимости и запустить `next build` здесь не удалось. После `npm install` следует выполнить `npm run build`, затем проверить все внешние переходы, изображения, мобильную навигацию и тарифные сценарии в браузере.

## База данных (Prisma + PostgreSQL)

1. Создайте базу PostgreSQL (13+) и скопируйте `.env.example` в `.env`, заполните `DATABASE_URL`, `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD`.
2. `npm install` (после установки автоматически выполняется `prisma generate`).
3. `npm run db:migrate`: применит `prisma/migrations/0_init` (исходная SQL-схема, включая CHECK-ограничения и индексы).
4. `npm run db:seed`: создаст администратора, двух ведущих-заглушек, три занятия и два отзыва. Тарифы-заглушки скрыты, реальные вносятся в админке. Повторный запуск безопасен.
5. Изменения схемы: правьте `prisma/schema.prisma`, затем `npx prisma migrate dev --name <описание>`.

Никогда не добавляйте `.env` и пароли в репозиторий (он публичный). На Vercel значения задаются в Project → Settings → Environment Variables.
